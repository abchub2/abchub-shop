관리자 인증

이 홈페이지의 GitHub 저장소에 쓰기 권한이 있는 관리자만 저장할 수 있습니다.

인증 토큰은 현재 화면의 메모리에서만 사용하며, 저장하지 않습니다. 새로고침하거나 로그아웃하면 다시 인증해야 합니다.

처음 사용하시나요? 관리자 인증 준비
  1. 저장소 관리자 GitHub 계정으로 Fine-grained personal access token 만들기 ↗를 여세요.
  2. Resource owner를 abchub2로 선택하고, Repository access에서 Only select repositories → abchub-shop을 선택하세요.
  3. Repository permissions의 Contents를 Read and write로 설정하고 만료일을 지정하세요. Metadata 읽기 권한은 기본 포함됩니다.
  4. 생성한 토큰을 위 입력칸에 넣으세요. 토큰을 채팅이나 메일로 보내지 마세요. 조직 승인이나 저장소 보호 규칙이 있으면 해당 관리자 설정을 먼저 완료해야 합니다.
