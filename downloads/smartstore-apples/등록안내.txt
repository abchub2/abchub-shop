이팜 | 네이버 스마트스토어 사과 상세페이지 3종

1. 바로 사용하는 HTML
01-fuji-5kg.html : 청송 부사사과 5kg
02-fuji-10kg.html : 청송 부사사과 10kg
03-shinano-gold-5kg.html : 청송 시나노골드사과 5kg 중대과

해당 HTML 파일을 메모장 등 텍스트 편집기로 열어 전체 내용을 복사한 다음,
스마트스토어 상품 등록/수정 > 상세설명 > HTML 작성 영역에 붙여 넣으세요.
HTML 파일 자체를 첨부하는 방식이 아닙니다. 저장 전 PC/모바일 미리보기를 확인하세요.
각 HTML에는 abchub.kr에 올린 이미지의 HTTPS 주소가 포함되어 있습니다.
이 이미지 주소를 삭제하거나 변경하면 상세페이지 사진이 표시되지 않으므로 경로를 유지하세요.

2. 네이버에 직접 이미지를 올리는 방법
외부 이미지 호스팅을 사용하지 않으려면 각 상품의 -images 폴더에 들어 있는
01.jpg~08.jpg를 숫자순으로 상세설명 편집기에 업로드하세요.
가로 860px 이미지이며, 문구와 가격이 포함되어 있습니다.
가격이나 배송 조건을 바꾸면 해당 상세페이지 이미지도 함께 수정해야 합니다.

3. 상품 등록값
상품 1) 청송 부사사과 5kg 소과 중대과 무료배송
기본 판매가 22,000원 / 옵션명: 크기
소과: 옵션 추가금 0원 → 최종 22,000원
중대과: 옵션 추가금 6,000원 → 최종 28,000원

상품 2) 청송 부사사과 10kg 소과 중대과 무료배송
기본 판매가 31,000원 / 옵션명: 크기
소과: 옵션 추가금 0원 → 최종 31,000원
중대과: 옵션 추가금 11,000원 → 최종 42,000원

상품 3) 청송 시나노골드사과 5kg 중대과 무료배송
판매가 28,000원 / 중대과 단일 구성. 불필요한 추가금 옵션은 만들지 않습니다.

공통) 원산지: 국내산 > 경상북도 > 청송군
배송비: 무료 / 택배사: 우체국택배
표시 문구: 오전 7시까지 주문 시 당일 배송 접수
당일 접수는 당일 도착을 의미하지 않습니다. 휴무일에는 다음 접수 가능일 접수로 안내했습니다.
실제 상품 설정의 발송기한·주문마감시간·휴무일도 판매 운영과 일치하도록 설정하세요.
가격은 HTML이 자동으로 설정해 주지 않습니다. 판매가·옵션 추가금·배송비를 상품 등록 화면에서 별도로 입력하세요.

4. 함께 들어 있는 파일
*-preview.html : 인터넷 연결 없이 볼 수 있는 미리보기. images 폴더와 함께 보관하세요.
*-editable.html : 텍스트와 색상 등을 수정할 수 있는 인라인 HTML 원본.
*-full.jpg : 상세페이지 전체를 이어 붙인 확인용 이미지.
images/*-thumbnail-1000.jpg : 1000×1000 대표이미지 후보.
images/*-ai.jpg : AI 생성 사진 원본 JPG.
상품등록값.csv : 최종 판매가·옵션 추가금 확인용.

5. 판매자 화면에서 반드시 별도로 입력할 정보
실제 생산자/포장자, 생산연도 또는 포장일(해당 항목), 실제 규격과 중량 기준,
재고, 반품 배송비·반품지, 소비자 상담 연락처 및 농산물 상품정보제공고시의 필수항목을
판매하는 실제 상품에 맞게 작성하세요. 확인되지 않은 생산자, 수확연도, 당도 수치,
친환경 인증, 무농약, 산지 직송, 구체적인 포장재, 과수 수량은 임의로 넣지 않았습니다.
등록 화면의 필수정보는 상세페이지 파일만으로 대체되지 않습니다.

6. 이미지와 배송 문구
사진은 이번 작업에서 AI로 새롭게 생성했습니다. 타 판매자 사진·우체국 로고·타사 상표·
기존 상세페이지 디자인은 사용하지 않았습니다. AI 사진은 실제 출고 상품의 증빙 사진이 아니며,
상세페이지에 AI 연출 이미지라는 사실을 표시했습니다. 실제 상품 상태와 대표성이 맞는지
확인한 뒤 사용하세요. 독점 저작권이나 제3자 권리 비침해를 법적으로 보증하는 문서는 아닙니다.
택배사 전체를 비교한 파손율 근거를 확인하지 못해 ‘파손율 최저’, ‘손상이 가장 적다’는
표현은 넣지 않았습니다. 우체국택배 이용 사실과 무료배송, 접수 시각을 중심으로 강조했습니다.
